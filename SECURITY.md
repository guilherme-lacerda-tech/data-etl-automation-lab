# Security

This repository is designed for public portfolio use.

Allowed content:

- Fictional organizations.
- Fictional device or ticket IDs.
- Synthetic events, logs and datasets.
- Publicly explainable architecture.
- Generic operational rules.

Forbidden content:

- Corporate source code.
- Real customer, employer or client data.
- Private endpoints, URLs or IP addresses.
- Credentials, tokens or API keys.
- Real logs.
- Internal business rules.
- Proprietary protocol details.
- Screenshots or exports from production systems.

Before every push, scan the repository for secrets, real identifiers and
corporate references. If there is any doubt, do not publish that content.
