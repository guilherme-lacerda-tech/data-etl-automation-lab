# ADR 0001 - Independent Public Implementation

## Status

Accepted.

## Context

`data-etl-automation-lab` is a public portfolio project. It must demonstrate technical skills
without exposing any employer or client assets.

## Decision

The project is implemented from scratch with fictional inputs, synthetic
data and generic rules.

## Consequences

- Safe public evolution after review.
- Clear interview narrative.
- Some real-world complexity is represented through simulation.
